# Cepsa Frontend (React + Vite + Tailwind CSS)

Frontend Web Application & Admin Management Portal for Cepsa Tiles & Bathware.

## Features
- **Public Showcase Website**:
  - Hero banner & brand story (like Duragres)
  - Category Showcase (Glazed Vitrified Tiles, Wall Tiles, Floor Tiles, Outdoor, Bathware, Sanitaryware)
  - Interactive Product Catalog with filtering by Category, Finish (Glossy, Matt, Carving, Satin), Size (e.g. 600x1200mm, 800x1600mm), Color, and Application (Living Room, Bathroom, Kitchen, Commercial)
  - Detailed Product View with zoom, specs, finish textures, and inquiry form
  - E-Catalogue preview / download system
  - Contact & Dealer Locator / Inquiry modal
- **Owner Admin Portal**:
  - Secure Login interface
  - Dashboard analytics overview (Total products, categories, recent inquiries)
  - Product Management Table (Search, Filter, Pagination)
  - Add New Product Modal/Form (Title, SKU, Category, Finish, Size, Thickness, Images upload, Specifications)
  - Edit & Delete Product controls
  - Category & Specification management
